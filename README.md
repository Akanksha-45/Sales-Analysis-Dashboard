# Sales Analysis Dashboard

## Overview
An interactive Power BI dashboard to analyze sales performance across regions, products, payment methods, and salespersons.

## Tools Used
- Power BI
- DAX
- Power Query
- CSV

## KPIs
- Total Sales
- Total Orders
- Total Profit
- Profit Margin
- Average Order Value

## Features
- Interactive slicers
- Sales trend analysis
- Product analysis
- Payment method analysis
- Salesperson performance
